##### 리액트로 만든 웹서비스들을 보통 리액트 앱이나 리액트 어플리케이션이라고 부름.

- 리액트로 만들어진 대다수의 웹 서비스들은 단순한 웹 페이지의 기능을 넘어서 넷플, 페북, 인스타처럼 사실상 어플리케이션에 가까울 정도로 매우 다양한 기능을 제공하고 있기 때문에, 단순한 웹이 아니라 웹 브라우저 위에서 동작하는 애플리케이션 같다라고 해서 보통은 리액트 앱, 리액트 애플리케이션이라고 부른다.
- 다양한 방식으로 생성할 수 있다.

##### 사실 리액트도 npm에 등록된 자바스크립트의 라이브러리임

- 그래서 node.js 패키지 만들어서
- React 라이브러리 설치하고
- 기타 도구 설치 및 설정하면 됨 (입문자에게는 권장하기 어려움)
  - 대신 훨씬 쉬운 방식인 **Vite**라는 차세대 프론트엔드 개발 툴을 이용해서 기본 설정이 미리 다 완료된 상태의 리액트 앱을 생성할 것임. (리액트 공식 문서에서도 Vite를 권장하고 있다.)

-----



##### 방법

1. 터미널에 `npm create vite@latest` 명령어로 vite으로 작동되는 리액트앱 생성
2. 프로젝트 이름, 프레임워크 등의 정보를 설정함
3. **(초기설정)** 근데 Node_modules나 package-lock.json 파일이 없음 –> 그래서 package.json의 정보를 기반으로 설치해야 함
   - 터미널에서 `npm i` 입력
   - Node_modules에 엄청난 수의 라이브러리들이 추가됨…!
4. npm run dev로 리액트앱 가동



## 추가된 파일 설명

- **`public` 폴더**

  : public 폴더에 기본으로 `bit.svg`이라는 이미지 파일이 생겼음. 이 public 폴더의 용도는 이런 svg나 png, jpg 같은 **이미지 파일**들을 보관하거나, **폰트나 동영상**처럼 코드가 아닌 정적인 파일들을 보관하는 저장소



- **`src` 폴더**

  : source의 약자. 실제로 작성하게 될 리액트나 JS 코드들을 보관하는 폴더. App.css 같은 css 파일이나 App.jsx 같은 JS 파일이 저장되어 있음.

  - **`jsx` 확장자** : 리액트에서 사용되는 특수한 확장자. **리액트 코드가 작성되는 공간**



- **`assets` 폴더** (src 폴더속)

   : react.svg라는 이미지 파일이 있는데 assets 폴더 안에도 public 폴더처럼 이미지나 폰트 등의 정적 파일을 보관할 수는 있음. 다만 차이가 있음! 추후 공부.



- **`.eslintrc.cjs` 파일**

  : eslint라는 도구의 설정 파일

  - `eslint` : 개발자들 사이의 코드 스타일을 통일하는 도구



- **`vite.config.js` 파일**

  : vite의 옵션을 설정하는 파일



---

##### package.json 파일을 보면 리액트 앱을 실행시킬 수 있는 4가지의 명령어가 미리 설정되어 있음

- **dev** : 리액트 앱을 개발용으로 실행시켜보는 명령어 (`npm run dev` –> vite가 리액트 앱을 작동시켜서 리액트 앱에 접속된 로컬호스트가 나옴)
  - **h** : 단축키들 알려줌
    - **r** : 서버 다시 실행
    - **u** : 서버의 주소를 보여줌
    - **o** : 브라우저에서 열기
    - **c** : 콘솔 지워줌
    - **q** : 종료 (npm run dev 하면 재실행)

###### 비동기작업 처리하기 2. Promise
# Promise 객체

: 비동기작업을 효율적으로 처리할 수 있게 도와주는 자바스크립트의 내장 객체

–> setTimeout 같은 비동기작업을 감싸고 있음.

- 기능 1. 비동기 작업 실행

- 기능 2. 비동기 작업 상태 관리

- 기능 3. 비동기 작업 결과 저장



### Promise는 비동기 작업을 진행 단계에 따라서 세 가지의 상태로 나누어서 관리

1. **대기** : 아직 작업이 완료되지 않은 상태 (비동기 작업이 진행중)
2. **성공** : 비동기 작업이 별 다른 문제없이 성공적으로 마무리된 상태
3. **실패** : 비동기 작업이 실패한 상태 (네트워크 에러, 코드 에러 등으로)



- **해결(resolve)** : 비동기 작업이 대기 상태였다가, 작업이 성공적으로 완료되어서 성공 상태로 바뀌는 것
- **거부(reject)** : 비동기 작업이 대기 상태였다가, 모종의 이유로 실패해서 실패 상태로 바뀌는 것



### 예시

#### 유튜브 영상 로딩 중(버퍼링창) 

–> 대기(pending)



#### 영상 로딩이 완료되어서 시청이 가능하게 함 

–> 해결(resolve)



#### 시청이 가능해진 상태

–> 성공(fulfilled)



#### 영상 로딩에 실패함

–> 거부(reject)



로딩에 실패해서 영상을 볼 수 없는 상태

–> 실패(rejected)
